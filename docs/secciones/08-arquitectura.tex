El contexto considera cuatro actores: estudiante, docente, coordinación y administración. Los sistemas externos identificados son el servicio de correo, el almacenamiento de archivos y el proveedor de validación de datos de cargas.
\subsection{C4 nivel 2: contenedores}\pendiente{Consultar la figura 2 del artículo de Atodiresei y colaboradores~\cite{atodiresei-c4-2024}. Mostrar en un editable los servicios, bases de datos y comunicaciones, e identificar lo implementado y lo propuesto.}
Los contenedores considerados son la SPA Angular, la API Spring Boot, la base de datos PostgreSQL y los servicios externos de correo, almacenamiento y validación. La comunicación entre la SPA y la API se realiza mediante HTTP/JSON.
