\section{Modelo de comunicación entre servicios}
La SPA Angular consume la API mediante peticiones HTTP/JSON bajo \texttt{/api}. En desarrollo, el proxy redirige esas peticiones al servicio backend en el puerto 8080 y el interceptor \texttt{credentialsInterceptor} añade credenciales a cada petición. El backend valida una sesión HTTP con cookie \texttt{httpOnly}, \texttt{SameSite=Lax} y tiempo de espera de 30 minutos. Las operaciones de carga de recursos usan \texttt{multipart/form-data}.

Las alternativas evaluadas para la comunicación entre servicios son REST/HTTP JSON síncrono, gRPC y mensajería asíncrona. REST mantiene la autenticación por sesión y permite depurar cada petición; gRPC ofrece contratos tipados y eficiencia de serialización con una capa intermedia para el navegador; la mensajería asíncrona elimina la dependencia temporal a costa de consistencia eventual, orden de mensajes e infraestructura de broker. Los datos críticos considerados en el análisis son solicitudes, programación de sesiones, asistencia y estados.
